# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in TraceShrink, please report it responsibly.

**Do NOT open a public issue.**

Email: timur.rakhmatullin86@gmail.com

Include:
- Description of the vulnerability
- Steps to reproduce
- Impact assessment

I will acknowledge receipt within 48 hours and aim to release a fix within 7 days for critical issues.

|---------|-----------|
| latest  | Yes       |
